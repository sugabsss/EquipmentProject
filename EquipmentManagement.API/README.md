🌐 Application Programming Interface (API):
Camada mais externa do sistema composto por :

	- Controllers : Aqui é utilizado para expor os endpoints da API, permitindo que os clientes possam interagir com o sistema. Os controllers são responsáveis por receber as requisições dos clientes, processá-las e retornar as respostas adequadas. Eles atuam como uma ponte entre os clientes e as camadas internas do sistema, garantindo que as operações sejam realizadas de forma eficiente e consistente.
	- Swagger : Aqui é utilizado para documentar a API, permitindo que os clientes possam entender como utilizar os endpoints disponíveis. O Swagger é uma ferramenta popular para documentação de APIs, pois fornece uma interface interativa que permite aos clientes explorar os endpoints e testar as requisições diretamente na documentação. Ele é responsável por garantir que a documentação seja clara, completa e fácil de usar para os clientes.
	- Middleware : Aqui é utilizado para adicionar funcionalidades adicionais à API, como autenticação, logging, tratamento de erros, etc. O middleware é uma camada intermediária que pode ser configurada para processar as requisições e respostas da API, permitindo a personalização do comportamento da API de acordo com as necessidades do sistema. Ele é responsável por garantir que as operações sejam realizadas de forma eficiente e consistente, adicionando funcionalidades adicionais à API conforme necessário.
	- Autenticação : Aqui é utilizado para garantir que apenas usuários autorizados possam acessar os endpoints da API. A autenticação é um processo de verificação da identidade do usuário, geralmente por meio de credenciais como nome de usuário e senha, tokens de acesso, etc. Ela é responsável por garantir a segurança da API, impedindo o acesso não autorizado e protegendo os dados sensíveis do sistema.
	- JSON Web Tokens (JWT) : Implementação de JWT para autenticação e autorização de usuarios na API, criando tokens e cookies para manter a sessão do usuário. O JWT é um padrão aberto para criação de tokens de acesso que podem ser usados para autenticação e autorização em sistemas web. Ele é responsável por garantir a segurança da API, permitindo que os usuários se autentiquem e autorizem suas ações de forma segura e eficiente. O JWT é uma escolha popular para autenticação em APIs devido à sua simplicidade, flexibilidade e suporte a diversos casos de uso.
